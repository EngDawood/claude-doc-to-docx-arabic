# تحويل مستندات Claude إلى ورد (عربي RTL و APA)

> إضافة (Plugin) لـ Claude تحوّل مستند Claude Doc إلى ملف ورد جاهز للتسليم: المستند العربي يخرج من اليمين لليسار بتنسيق الرسائل الجامعية السعودية، والإنجليزي بتنسيق APA 7، مع الصور والرسوم البيانية. النسخة الإنجليزية: [README.en.md](./README.en.md)

## لماذا؟

يتيح Claude Docs تصدير المستند بصيغة `.docx`، لكن هذا التصدير لا يضبط الاتجاه من اليمين لليسار، ويُسقط الصور والرسوم البيانية. فتخرج الفقرات العربية محاذاة لليسار، وتُقرأ الجداول من الجهة الخطأ، ويحتاج كل فصل إلى إعادة تنسيق يدوية في الوورد. تستبدل هذه الإضافة ذلك التصدير بسكربتين يبنيان الملف بالاتجاه الصحيح والتنسيق المطلوب من البداية.

## ماذا تفعل؟

أعطِ Claude رابط المستند واطلب تحويله إلى ورد، فيقوم بما يلي:

1. يقرأ المستند ويصدّر كل تبويب فيه بصيغة markdown.
2. يجلب كل صورة في المستند، ويلتقط كل رسم بياني كصورة.
3. يختار السكربت المناسب للغة المستند ويبني ملف `.docx`.
4. يعرض صفحة من النص وصفحة فيها جدول وصفحة فيها قائمة وصفحة فيها صورة، ليتحقق من التنسيق.
5. يسلّم الملف باسم عنوان المستند.

وإذا ظهر خلل أثناء العمل، يحدد سببه ويقترح تعديلاً على الإضافة نفسها، ولا يطبّقه إلا بعد موافقتك وتأكيدك أن الناتج الجديد صحيح.

### يدوياً

انسخ المجلد `skills/doc-to-word-rtl` إلى `.claude/skills/` داخل المشروع، أو إلى `~/.claude/skills/` لحسابك.

تحتاج Python 3 مع مكتبة `python-docx` (`pip install python-docx`). أما LibreOffice و `pdftoppm` فيُستخدمان للتحقق البصري فقط.


ويمكن تشغيل السكربتين مباشرة على أي ملف markdown:

<div dir="ltr">

```bash
python3 skills/doc-to-word-rtl/scripts/md_to_docx_rtl.py chapter.md chapter.docx --images images.json
python3 skills/doc-to-word-rtl/scripts/md_to_docx_en.py paper.md paper.docx --paper a4
```

</div>

ملف `images.json` قائمة بالصور بترتيب ظهورها في المستند: `[{"alt": "...", "path": "..."}]`. وتعمل كذلك صور markdown العادية `![وصف](مسار/الصورة.png)`.

## التنسيقات الافتراضية

### العربي: `md_to_docx_rtl.py`

| العنصر | الافتراضي |
|---|---|
| الصفحة | A4، هوامش 2.54 سم، رقم الصفحة في المنتصف |
| النص | Traditional Arabic بحجم 16، محاذاة من الجانبين، تباعد 1.08 |
| العناوين | `#` بحجم 22، `##` بحجم 18، `###` بحجم 16، بخط عريض. في الوسط إذا بدأت بـ المحور أو الفصل أو المراجع، وإلى اليمين فيما عدا ذلك |
| الجداول | الأعمدة من اليمين لليسار، حجم 14، رأس رمادي يتكرر في كل صفحة، والصف لا ينقسم بين صفحتين |
| عناوين الجداول | `جدول (n): ...` بخط عريض في الوسط، ملاصق لجدوله |
| القوائم | كل قائمة مرقمة تبدأ من 1 |
| المراجع | مسافة معلّقة 0.635 سم |
| الصور والرسوم | في الوسط، بعرض النص كحد أقصى، والتعليق تحتها |

الخيارات: `--ar-font` و `--en-font` و `--size` و `--table-size` و `--color` و `--line` و `--margins` و `--paper a4|letter` و `--images` و `--keep-byline` و `--dir rtl|ltr|auto`.

### الإنجليزي: `md_to_docx_en.py` بتنسيق APA 7

| العنصر | الافتراضي |
|---|---|
| الصفحة | US Letter، هوامش 2.54 سم، رقم الصفحة أعلى اليمين |
| النص | Times New Roman بحجم 12، تباعد مزدوج، مسافة بادئة 1.27 سم لأول سطر |
| العناوين | `#` عنوان البحث، ومن `##` إلى `#####` تقابل مستويات APA من 1 إلى 4 |
| الجداول | `Table n` بخط عريض وتحته العنوان مائلاً، بخطوط أفقية فقط |
| الملاحظات | `Note.` مائلة تحت الجدول |
| المراجع | تبدأ في صفحة جديدة، بمسافة معلّقة 1.27 سم |
| الصور والرسوم | في الوسط، بعرض النص كحد أقصى، والتعليق تحتها |

الخيارات: `--font` و `--size` و `--table-size` و `--line` و `--margins` و `--paper a4|letter` و `--images` و `--keep-byline`.

## الحدود

- الرسم البياني يصل إلى الورد صورةً ثابتة، لا رسماً قابلاً للتعديل.
- التعليقات في المستند لا تُنقل، والحواشي السفلية تتحول إلى نص عادي.
- التحقق البصري يجري في LibreOffice، وقد لا يتوفر فيه خط Traditional Arabic، فهو يحكم على التنسيق لا على شكل الخط.
